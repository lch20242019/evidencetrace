## 2026-07-10 — implementation begins

- The product is a factual CI for technical Markdown, not a general report
  generator and not a truth detector.
- Phase 0 uses controlled fictional sources so every expected evidence span is
  stable and reviewable without network access.
- The working name has a real GitHub collision. Keeping it locally while
  blocking publication demonstrates that availability checks are gates, not
  checkbox theater.
- The deterministic core will preserve source line locations before any model
  work begins. This makes later Agent output auditable rather than trusting
  model-produced locations.
